Here's what we shipped in September.

## See your app's memory usage in production 💾

You can now see how much memory your app uses in production on Android and iOS, and whether it's getting worse. The new Memory page shows memory usage across app versions.

You can study memory usage by the device's total RAM to check whether a particular tier is struggling more than others. You can also filter by device manufacturers and any device too.

![Memory by device table showing p50, p90 and p95 memory and session counts for each device total memory range](/blog/assets/product-update-september-2026-memory-by-device-card.webp)

Sessions with unusually high memory usage are automatically flagged. You can view session replay of such sessions and understand where the problem lies.

Read our post on [understanding memory usage of Android apps](/blog/android-memory-monitoring) for more details.

## A new filter bar on every page 🔎

Filters used to be a few fixed dropdowns plus a "More filters" dialog of checkbox lists. You could only include values from those lists and the UI was a bit clunky.

The new filter bar lets you build the filter you actually have in mind. You can exclude values, match part of a value, filter on custom attributes the same way as any other key, and combine conditions with AND and OR, including groups inside groups. If you prefer typing, you can edit the same filter as text.

Filters are now part of the page URL. If you copy the link and send it to a teammate, they open the same filtered view.

## A better errors page ✨

The errors list now shows when each error was last seen, a trend of how often it happens, and how many users and sessions it affected.

![Errors list showing last seen, trend, instances, sessions and users for each error](/blog/assets/product-update-september-2026-errors-list-card.webp)

## See every screen in session replay 📸

Session replay now collects layout snapshots for every screen user visits automatically. Earlier layout snapshots were only collected on clicks. When you open a session to find out why something went wrong, you can now see each screen the user went through.
